# PracticaAlgoritmia2

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)

Proyecto Android desarrollado como práctica para la asignatura de **Algoritmia 2**. Implementa y visualiza diversas estructuras de datos avanzadas y algoritmos complejos aplicados en un entorno móvil.

## 🚀 Características

- **Estructuras de Datos Avanzadas**: Implementación y gestión eficiente de árboles, grafos y otras estructuras complejas.
- **Algoritmos Eficientes**: Uso de algoritmos de optimización, caminos mínimos y recorridos.
- **Interfaz Android**: Visualización interactiva construida con Android y Java.

## 🛠️ Tecnologías Utilizadas

- Java
- Android SDK
- Gradle

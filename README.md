# 📱 PracticaAlgoritmia2

![Android](https://img.shields.io/badge/Android-3DDC84?style=for-the-badge&logo=android&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=java&logoColor=white)

Proyecto Android desarrollado como práctica para la asignatura de **Algoritmia 2**. Implementa y visualiza diversas estructuras de datos avanzadas y algoritmos complejos (basados en grafos, mapas y colas) aplicados en un entorno móvil interactivo (clon de Hundir la Flota / Battleship).

---

## 🚀 Características

- **Estructuras de Datos Avanzadas**: Implementación manual y gestión eficiente de `LinkedListQueue`, `UnsortedArraySet`, y `UnsortedArrayMapping`.
- **Algoritmos Eficientes**: Uso de algoritmos de optimización, caminos mínimos y recorridos en tablero.
- **Interfaz Android**: Visualización interactiva construida con Android (Java), utilizando vistas personalizadas y XML Layouts.
- **Conectividad**: Soporte de comunicación en tiempo real a través de WebSockets (`GestorWebSocket.java`).

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: Java
- **Plataforma**: Android SDK (Android Studio)
- **Construcción**: Gradle (Kotlin DSL)
- **Control de Versiones**: Git

## 📈 Mejoras Aplicadas Recientemente
- Refactorización de código fuente (p. ej. `LinkedListQueue.java`) con mejores convenciones de nomenclatura (head/tail en lugar de p/q).
- Incorporación de comentarios Javadoc detallados en las estructuras de datos principales para mejorar su comprensión académica.
- Estructuración y limpieza general de código.
